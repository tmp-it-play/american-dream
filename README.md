# American Dream (임시)

## 목적

2026 광주소프트웨어마이스터고 글로벌현장체험학습에서 겪은 경험을 친구, 선생님, 가족에게 전한다.

**그때 들었던 생각과 분위기**를 중심으로 회고하고, 나만의 방식으로 표현한다.

## 컨셉: 꿈 같았던 미국

미국 여행이 꿈만 같았다는 감각을 **드림코어 / 리미널 스페이스** 문법으로 표현한다.

- **safe room.** 드림코어의 "대기실"을 실제로 묵었던 호텔 객실 하나로 만든다.
  - **플레이어는 방 밖으로 나갈 수 없다.** 문은 열리지 않는다.
  - **창밖은 라스베이거스 야경**이다.
- **camera view.** 몰입감과 극적인 연출을 위해 **1인칭 올드 카메라 / 바디캠 시점**을 쓴다.
